Headlamp need a service account token for authentication， which can be generated by following commands:
Usage:

    kubectl create token SERVICE_ACCOUNT_NAME [options]

Examples:

    # 1 month TTL token for [headlamp-viewer]
    kubectl create token headlamp-viewer -n headlamp --duration=720h

    # 1 year TTL token for [headlamp-viewer]
    kubectl create token headlamp-viewer -n headlamp --duration=8760h
