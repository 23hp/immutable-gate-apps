VictoriaMetrics k8s stack (vmsingle + vmagent + vmalert + alertmanager + Grafana + node-exporter + kube-state-metrics).

Everything is deployed into the `victoria-metrics` namespace.

Grafana admin password is generated by the chart on first install, read it with:

    kubectl get secret -n victoria-metrics victoria-metrics-k8s-stack-grafana \
      -o jsonpath='{.data.admin-password}' | base64 -d

Notes:
- Dashboards and default rules are downloaded from GitHub by a post-install/post-upgrade
  `sync-job`, so the cluster needs outbound access to `raw.githubusercontent.com`.
- Alertmanager routes everything to a `blackhole` receiver by default; configure
  `alertmanager.config` in the overlay values to get notifications.
- `kubeControllerManager`, `kubeScheduler`, `kubeEtcd` and `kubeProxy` scraping is disabled in
  the lab overlay. Re-enable them if your control plane exposes the metrics on a node reachable address.
